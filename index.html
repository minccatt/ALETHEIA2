01 / INPUT

사업 데이터

월별 매출, 변동비, 고정비를 입력하세요. 비용은 서로 중복되지 않게 구분하며 모든 금액은 원 단위입니다.

직접 입력 · 데이터는 이 브라우저 메모리에서만 처리됩니다.
월매출 (원)변동비 (원)고정비 (원)관리

입력 기준과 분석 범위

변동비는 판매량에 따라 달라지는 재료비 등, 고정비는 임대료처럼 판매량과 무관한 비용입니다. 환불은 매출에 반영한 순매출로 입력하고, 입력 금액은 0 이상의 정수여야 합니다. 연속된 월을 입력해 주세요. 데이터는 최대 120개월, 금액은 항목별 1조 원 이하를 지원합니다. 이익은 매출 − 변동비 − 고정비로 계산하며, 입력하지 않은 세금·비용은 포함하지 않습니다.

02 / OVERVIEW

월별 매출과 비용

규칙 기반 해석

지금 점검할 부분

    계산 근거 확인

    총비용 = 변동비 + 고정비
    입력 비용 기준 이익 = 매출 − 총비용
    이익률 = 이익 ÷ 매출 × 100
    전월 대비 변화율 = (최근 월 − 직전 월) ÷ 직전 월 × 100
    직전 값이 0이면 변화율을 계산하지 않습니다.

    03 / SCENARIOS

    조건이 달라지면 어떨까요?

    조건부 계산

    입력 기간의 월평균을 기준으로 계산합니다. 판매량 변화는 사용자가 정하는 가정이며, 가격 변화에 자동으로 연결하지 않습니다.

    시뮬레이션 조건

    시뮬레이션의 가정과 한계

    월평균 매출 × (1 + 가격 변화율) × (1 + 판매량 변화율), 월평균 변동비 × (1 + 단위당 변동비 변화율) × (1 + 판매량 변화율), 월평균 고정비 + 고정비 증감으로 계산합니다. 모든 상품에 같은 변화율이 적용되고 상품 구성은 유지된다고 가정합니다. 계절성·고객 반응·시장 변화는 반영하지 않으며 실제 미래 성과나 발생 확률을 뜻하지 않습니다.
