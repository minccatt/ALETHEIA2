## 4. 앱 시연

### 시연 순서

1. 초기 화면을 보여 줍니다.
2. 사용자의 입력 또는 선택을 보여 줍니다.
3. 핵심 버튼을 누릅니다.
4. 결과와 판단 이유를 설명합니다.
5. 사용자가 최종적으로 선택할 수 있는 행동을 보여 줍니다.

### 시연에 사용할 입력

```text
발표 중 사용할 입력값을 미리 작성하세요.
```

### 기대 결과

```text
입력 후 화면에 나타나야 하는 결과를 작성하세요.
```

### 발표 문장

> 먼저 사용자가 **[입력 또는 선택]**을 합니다.  
> **[버튼 이름]** 버튼을 누르면 **[결과]**가 나타납니다.
>
> 이 결과는 **[판단 규칙]**에 따라 만들어졌습니다.  
> 앱은 결과만 보여 주지 않고 **[판단 이유]**도 함께 설명합니다.
>
> 사용자는 이 결과를 참고한 뒤 **[최종 선택]**을 직접 할 수 있습니다.

## 6. 왜 ‘무해한 AI’인가?

### 확인 항목

- 개인정보를 수집하지 않는가?
- 특정 사람이나 집단을 차별하지 않는가?
- 혐오·폭력·위험 행동을 추천하지 않는가?
- 판단의 한계를 사용자에게 알리는가?
- 사용자가 최종적으로 결정할 수 있는가?

### 발표 문장

> 이 기능이 잘못 판단하면 **[발생할 수 있는 문제]**가 생길 수 있습니다.  
> 이를 예방하기 위해 **[안전 장치]**를 적용했습니다.
>
> 또한 AI의 결과를 정답으로 강요하지 않고  
> 사용자가 **[사용자의 최종 선택]**을 할 수 있게 만들었습니다.
>
> 이러한 점에서 저희 프로젝트는 사람에게 도움을 주면서도  
> 위험을 줄이는 ‘무해한 AI’를 표현합니다.
