---

## 시작하기

### 1. 프로젝트 실행

터미널에서 다음 명령을 실행합니다.

```bash
npm start
```

브라우저에서 다음 주소를 엽니다.

```text
http://localhost:3000
```

GitHub Codespaces에서는 `PORTS` 탭에서 3000번 포트를 엽니다.

### 2. 프로젝트 진행 순서

1. `PROJECT_PLAN.md`를 작성합니다.
2. 교사의 기획 승인을 받습니다.
3. `index.html`, `styles.css`, `app.js`를 수정합니다.
4. 기능 하나를 구현할 때마다 실행하고 테스트합니다.
5. AI 활용 과정은 `AI_LOG.md`에 기록합니다.
6. 안전 설계는 `SAFETY_CHECK.md`에서 확인합니다.
7. 테스트 결과는 `TEST_CHECKLIST.md`에 기록합니다.
8. 역할 교대는 `TEAM_LOG.md`에 기록합니다.
9. 발표는 `docs/PRESENTATION_SCRIPT.md`를 이용해 준비합니다.
10. 마지막 정상 결과를 GitHub에 커밋하고 푸시합니다.

## 15. 저장소 이용 주의사항

- 개인정보를 코드나 문서에 작성하지 않습니다.
- API 키, 비밀번호, 토큰을 저장소에 올리지 않습니다.
- AI가 만든 코드는 두 팀원이 직접 확인하고 테스트합니다.
- 이해하지 못한 코드를 그대로 사용하지 않습니다.
- 다른 사람의 코드나 이미지는 출처와 라이선스를 확인합니다.
